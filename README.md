# 🚀 Portfolio — Amandine Napolitano

Portfolio professionnel d'**Amandine Napolitano**, développeuse web freelance.

Ce projet a été conçu et développé de zéro avec **Vue 3** et **Vite**, avec une identité visuelle unique inspirée du pixel art, des univers digitaux et du jeu vidéo. 

L'objectif est de présenter mon parcours, mes compétences et mes réalisations tout en mettant en pratique mes compétences en développement front-end, intégration, responsive design et animation.
